# UI 与交互验收

## 视觉

- 390×844 逐页检查六个主页面：蓝白风格、图片、字体、圆角、底部导航及图标。
- 320×740 检查窄屏换行、水平溢出、导航和按钮遮挡。
- 内容页允许自然纵向滚动，底部内容不得被固定导航永久遮挡。
- 微信构建检查原生组件输出、资源引用和胶囊安全空间。

## 功能

- 首页入口、四个底部导航、医院详情返回、乐城介绍入口。
- 医院介绍/乐城介绍在首页下方切换，不改变页面地址；切换选中态与内容同步。
- 蓝色医院横幅数量与完整列表一致，无“查看全部”。
- 首页三家医院为一栏一张的大图卡片，整张卡片分别进入对应医院信息。
- 医院信息页有通栏大图、名称、地址、收藏、联系方式和介绍；“专家”角标、“入驻时间”、“公立”、“特许药械”、“名医专家”不出现。
- 医院信息页的特色科室、医生排班、就医指南按单列逐项展示；栏目定位、科室/医生入口、联系方式与返回均可用。
- 乐城介绍移除顶部介绍文案与底部园区导览；“乐城动态、国家政策、了解乐城”三个入口原地切换，下方内容与选中态同步，地址不变。
- 乐城动态与国家政策采用左图右文条目；动态点击后进入文章详情，政策详情原位展开/收起并包含日期和官方来源，首页与独立介绍页行为一致。
- 了解乐城为文章排版：标题、三组大图及正文纵向穿插；配图加载正常，正文和末段能完整滚动阅读。
- 查询框提示“搜索疾病、药品、项目”，分类为“批复项目、特许药械、亚健康项目”。三个分类共用“按科室 / 按疾病”两个筛选控件，选中项可见；科室、疾病和关键词共同过滤，不把医院类型当成疾病。
- 无查询标题、副标题、筛选图标或综合排序。科室按参考图左侧分类栏展示，疾病为整行分类块；从按钮下方展开，遮罩覆盖结果与底部导航。
- 两面板互斥，点击选项/当前筛选/遮罩均能收起；科室8项（含全部）、疾病7项（含全部）顺序与截图一致。长疾病名、末项滚动、320px窄屏和320×480短屏均可用。
- 筛选条件在切换分类、详情返回和刷新后保留；无结果可以重置查询，重置筛选不清除关键词。旧数字索引缓存不能隐藏记录。
- 批复项目和亚健康项目均使用案例资讯式大图列表，点击进入项目详情；特许药械使用包装示意图加资料行的列表，不出现“可用商保”。
- 三类详情均可看到信息表、详情、适用、规格和底部“落地医院”，不出现顶部医院标识条与滑动栏目导航；落地医院卡片可进入医院信息，返回后分类、关键词保持。
- 旧药品/器械分类入口及新分类名称均能进入对应内容，科室入口选中对应科室，旧医院类型入口转为可见关键词。
- 我的底部联系卡片放大，营业时间与地址分行、电话为大号绿色图标；320px和390px宽度不重叠，未配置号码显示待更新并禁用拨号。
- 医院 → 科室 → 医生 → 模拟预约逐层进入和返回；查询条件保留。
- 预约表单校验、重复预约拦截、预约记录与取消状态同步。
- 预约新增/取消生成系统通知，通知详情可进入对应预约。
- 收藏切换与持久化，浏览记录与个人中心统计一致。
- 消息分段切换、通知详情、标记已读。
- 本地咨询内容发送与静态回复、空消息不可发送、记录在我的咨询可见；返回后保留草稿。
- 免费问诊输入栏贴住底部导航，灰底聊天区域填满剩余空间；390×844、320×740及320×440屏幕无整页溢出。欢迎语与人工在线时间使用用户指定文字。
- 连续发送后自动显示最后消息，切换案例资讯和刷新后保留草稿与记录；键盘高度变化时输入栏跟随上移，收起后恢复导航。浏览器组件事件模拟检查已通过，微信真机软键盘仍需复核。
- 资料编辑、手机号校验、保存后个人中心同步。
- 帮助折叠、反馈保存与记录详情、设置及通知红点开关。
- 园区导览选中医院、交通方式切换及医院详情联动；新闻列表分类和文章详情。

## 异常路径

- 不存在的医院、科室、医生、药械及预约 ID 显示恢复入口。
- 从直接链接进入二级页面时，返回按钮可以恢复到对应入口。
- 零搜索结果可以清除筛选恢复列表。
- 空收藏、空咨询、空浏览记录均有下一步入口。

## 限制

已按用户补充的参考截图实现可见分类和展开样式；截图未展示的更多分类未自行编造，现有业务记录及分类关联仍为静态演示。

不声称后台、真实问诊、地图导航、登录或上线已完成。微信真机需提供 AppID 后在开发者工具中复核。
